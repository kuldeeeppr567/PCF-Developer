# PCF Controls Workspace

This folder contains all PCF controls generated by the PCF Developer Agent.

All controls share the root `node_modules/` via npm workspaces — no need to run `npm install` per control.

## First-Time Setup

From the **repository root**, run:

```bash
npm install
```

This installs shared dependencies once for all controls.

## Adding a New Control

When the PCF Developer Agent creates a control here, just run from root:

```bash
npm install
```

This links the new workspace in ~2 seconds (no re-download).

## Building a Specific Control

```bash
cd controls/YourControl
npm run build
```

## Building All Controls

From the root:

```bash
npm run build:all
```
