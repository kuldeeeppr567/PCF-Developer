# PCF Controls

This folder contains all PCF controls generated by the PCF Developer Agent.

Each control is **fully self-contained** — it has its own `node_modules/`, `package.json`, and builds independently.

## How It Works

When the PCF Developer Agent creates a new control:

1. Creates a folder here (e.g., `controls/Slider/`)
2. Runs `pac pcf init` to scaffold the project
3. Runs `npm install` **inside** the control folder to install dependencies
4. Writes the manifest, TypeScript, and CSS files
5. Runs `npm run build` to verify everything compiles

## Working with a Control

```bash
cd controls/YourControl

# Install dependencies (only needed once or after clone)
npm install

# Build
npm run build

# Preview in test harness
npm start watch
```

## Deleting a Control

Just delete the folder. Each control is independent — deleting one has no effect on others.
